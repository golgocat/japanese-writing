# Japanese Writing

Write, edit, summarize, or translate Japanese for work and personal communication. The main skill is [`SKILL.md`](SKILL.md).

用途・相手・媒体に合う日本語の執筆、翻訳、対訳、要約のためのスキルです。本体はリポジトリ直下の[`SKILL.md`](SKILL.md)です。

対訳だけを使いたい場合は[`skills/bilingual-line-by-line/SKILL.md`](skills/bilingual-line-by-line/SKILL.md)を単体で使えます。Claude Skillsのフォルダにそのまま置くか、ChatGPT等に本文を貼ってください。
