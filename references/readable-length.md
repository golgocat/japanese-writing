# 読める文字数ルール

AIが書く文章の長さを、形式ごとの字数上限で決める。
上限を超えたら、文字を小さくせずに削る。

- 字数はUnicodeのコードポイントで数える。改行は除き、空白と句読点は含める。Xだけは全角を2と数える。実測には`scripts/count_characters.mjs`を使う。
- 根拠の表記：〔出〕は出典あり、〔社〕は社内基準、〔提〕は出典がない提案値。詳細と出典は下の各章と出典一覧にある。

## 共通の原則

1. **1画面1メッセージ。** 1枚、1シーン、1投稿で伝えることは1つにする。〔社内基準V・D・J〕。SNS投稿への適用は〔提案値〕
2. **上限は「見る秒数×読む速さ」で逆算する。** 読む速さは5字/秒で計算する〔社内基準V〕。動画以外への適用は〔提案値〕。5秒で消えるストーリーなら25字。秒数が決まらない形式は、1文50字〔出典S1〕×文の数で決める。
3. **迷ったら削る。** 削る順は、重複、前置き、2つ目以降の例、形容。数字、期限、条件、次の行動は残す。
4. **小さくして収めない。** 先に削り、次に分ける。文字を小さくするのは最後。〔社内基準D〕
5. **数えてから出す。** `scripts/count_characters.mjs`で実測する。目分量で「収まった」としない。

### 1. ソーシャルバナー・広告画像

| 項目 | 上限 | 根拠 |
|---|---|---|
| 要素 | カテゴリ、見出し、補足、CTAの4つまで | 〔社内基準J〕画像バナーの既定 |
| 見出し（1:1） | 20字・2行以内・1行13字 | 〔出典S11〕20字。〔社内基準J〕2行。〔提案値〕「13文字の法則」（S17、一次研究なし）とNetflix字幕の1行13字（S9）を準用 |
| 補足（1:1） | 35字・2行以内 | 〔出典S11〕35字。〔提案値〕2行は、35字が1080幅・36pxでは1行に入らないため（Jの「補足1行」より優先） |
| 見出し・補足（1.91:1） | 15字・20字 | 〔提案値〕表示の高さが低いため、アナグラムの小型バナー（300×250）の値（S11）を準用 |

| 文字の面積 | 画像の20%未満 | 〔出典S12〕規則は撤廃済みで、推奨として残っている |

### 2. スライド（16:9）

| 項目 | 上限 | 根拠 |
|---|---|---|
| メッセージ | 1枚1つ。見出しは結論の文で書く | 〔社内基準D〕 |
| キーメッセージ | 13字 | 〔出典S3〕 |
| 見出し | 2行以内 | 〔提案値〕2行を超えると本文の行が残らない |
| 補足 | 40字 | 〔出典S3〕 |
| 1枚の総字数 | 105字 | 〔出典S3〕リーダー層の資料の平均値で、読みやすさの限界を測った値ではない |
| 1行 | 25字 | 〔提案値〕30pt（1080pで60px）の文字が横幅の約85%に入る約27字から切り下げ |
| 箇条 | 5項目まで、目安は3項目 | 〔社内基準J〕1グループ5項目 |
| 閲覧時間 | 1枚2分 | 〔出典S2〕10枚・20分 |
| 5秒テスト | 初見の人が5秒で要点を言える | 〔社内基準D〕。見出しと主文で25字（5秒×5字/秒）は〔提案値〕 |
| 文字サイズ（投影） | 30pt以上。16:9の高さの5.6%、1080pで60px | 〔出典S2〕30pt。割合は〔提案値〕高さ540pt（7.5インチ）の標準スライドで換算 |
| 文字サイズ（配布・画面で読む） | 10pt相当以上。1280幅で約13px | 〔社内基準D〕 |

## 記号と飾り線

em dash（—）、en dash（–）、横棒（―）を文中で使わない。読点・句点・「です」などで書き換える。デザインでも、ラベルや見出しの前に置く飾りの短い横線は使わない（em dashに見えるため）。範囲は「9〜17」のように「〜」で書く。コード、URL、識別子、引用は変えない。

ダッシュでつないでいた文は、2文に分ける。バナー、スライド、カルーセルのカテゴリやラベルは、文字だけで置く。

## AI向けプロンプト

```
次の上限を守って書いてください。字数は空白と句読点を含めて数えます。
- 1つの画面・投稿で伝えることは1つ。最初の1文に結論を書く
- 1文50字以内
- チャット回答は300字以内（目安200字）。300字以内なら見出しを付けない
- メールは件名20字、本文300字。X100字。Instagramは冒頭125字で要点を書く
- バナーは見出し20字・補足35字。スライドは1枚105字、見出しは2行まで
- 動画テロップは1行7字（最大11字）、1秒5字まで
- 箇条書きは3項目まで（最大5）
- 前置き、まとめの繰り返し、頼まれていない注意書きは書かない
- em dash（—）、en dash（–）、横棒（―）を文中で使わない。読点・句点・「です」などで書き換える。デザインでも、ラベルや見出しの前に置く飾りの短い横線は使わない（em dashに見えるため）。範囲は「9〜17」のように「〜」で書く。コード、URL、識別子、引用は変えない。
- 超えたら、重複、前置き、例の順に削る。数字、期限、条件は残す
- 書き終えたら字数を数え、超えていれば直してから出す
```
